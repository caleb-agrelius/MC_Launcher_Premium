# v2 usability fixes: milestones

Branch `dev/usability-fixes`, at `main` (`3954055`). A milestone is done once it builds, `launcher_checks`
passes, its feature docs are updated, and the change has been checked in the running app. Nothing is
committed (commits need the owner's GPG key) or pushed; all work is uncommitted in the working tree.
